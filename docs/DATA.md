# Data

All data is synthetic. Generated by `data/generate.py` with a fixed random seed. No real attendee data, no real speaker names, no copied conference text.

| Data | Size | Notes |
|---|---|---|
| Talks | ~30, 11:00-17:00 in time slots | original 2-3 sentence abstracts |
| Rooms | 12 over 3 floors | floor, step_free_entry, quiet_room, capacity, front_seating |
| Connectors | elevators A/B/C, stairs, 2 ramps, paths | minutes, step_free, status ok/down |
| Transcripts | 3-4 canned, timed chunks | session companion, Catch me up |
| Personas | Marcus, Priya, Sam | JSON in `docs/api-examples/` |
| Changes, reports, questions | empty at start | one seeded report for the Elastic Workflow demo |

## Each talk
id, title, abstract, speaker (fake), track, level, start, end, room, topics, and `access`: step_free_entry, captions (none|auto|live_human), interpreter, alt_text (none|ai_draft|verified), slides_available_ahead, sensory_note, quiet_room_nearby, front_seating.

## Rules
- Vary access facts on purpose (some stairs-only rooms, some no captions) so filtering and re-planning matter.
- Include the demo talks: "Securing Your Supply Chain Without Slowing Down" 2:00 PM Room 355; "Observability for Beginners" 3:00 PM Room 251; "Kubernetes RBAC in Plain English" 2:00 PM Ballroom E; "Supply Chain Security Q&A" 3:30 PM Room 251.
- Marcus's route to Room 355 goes through Elevator B so "Elevator B down" has an effect; Elevator C is the alternative.
- Two talks in the same slot match Priya's topics so a real backup exists.
- Test: every talk's room exists; every room is reachable from the entrance when all connectors are ok.

## Loading
`python data/ingest.py --reset` deletes and recreates the Elasticsearch indices and loads the JSON. Tell the group before running `--reset`.
